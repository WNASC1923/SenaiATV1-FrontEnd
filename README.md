## Introdução
Projeto de uma loja gamer fictícia feito com HTML, CSS e JavaScript.

## Briefing e referencia
Game Mania

Objetivo: Criar um site para apresentar produtos gamers.

Público-alvo: Pessoas interessadas em jogos e acessórios gamer.

Cores: Roxo, preto, branco, azul e cinza.

Páginas:
  
- Página inicial:  
	- Produtos  
	- Novidades  
	- Galeria  
- Login:  

Funcionalidades:  
- Menu de navegação.  
- Exibição de produtos e novidades.  
- Filtro de produtos por categoria.  
- Formulário de login.  
- Galeria de imagens.  

## Navegação
A página inicial mostra produtos, novidades e uma galeria. O link Login abre a página `login.html`. Na página de login existe um link para voltar à loja.

## Organização dos arquivos
index.html: página inicial.  
login.html: formulário de login.  
imagens/: imagens utilizadas no projeto.  
css/: estilos das páginas.  
js/: codigo do menu, filtro de produtos e validação do login.  

## Como abrir
Abra o arquivo `index.html` no navegador. Para testar o login, clique em Login.  

## Observação
O login é apenas uma simulação. Nenhum dado é enviado ou salvo.
